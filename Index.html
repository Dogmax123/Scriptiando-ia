Termos de Serviço Política de Privacidade

1. Termos de Serviço

Última atualização: August 2026

Ao utilizar o aplicativo ScriptandoIA e seus serviços de integração via API do TikTok, você concorda em cumprir estes termos.

1.1 Uso do Serviço

O ScriptandoIA é uma ferramenta projetada para automatizar a criação, renderização e postagem de vídeos curtos educativos focados em dicas de programação e tecnologia.

1.2 Responsabilidades do Usuário

  • O usuário garante que os conteúdos gerados e publicados cumprem as Diretrizes da Comunidade do TikTok.
  • Não é permitido utilizar a ferramenta para postar spam, conteúdos ofensivos, enganosos ou que infrinjam direitos autorais de terceiros.

1.3 Modificações e Interrupções

Reservamo-nos o direito de modificar, suspender ou descontinuar qualquer aspecto da ferramenta a qualquer momento, inclusive o acesso às APIs vinculadas.

2. Política de Privacidade

Última atualização: August 2026

A sua privacidade é fundamental para nós. Esta política descreve como tratamos dados de usuários ao integrar com a API do TikTok.

2.1 Coleta de Dados

O ScriptandoIA não armazena e nem vende dados pessoais dos usuários finais. As únicas informações coletadas e utilizadas durante a operação do script são:

  • Tokens de Autenticação OAuth: Utilizados exclusivamente para permitir o envio autorizado de vídeos para a conta do próprio usuário.
  • Métricas Básicas de Postagem: Confirmação de status de envio retornado pelas APIs oficiais.

2.2 Uso das APIs do TikTok

A integração utiliza a Content Posting API e o Login Kit do TikTok exclusivamente para realizar o upload e a publicação automatizada de vídeos autorizados pelo proprietário da conta.

2.3 Compartilhamento de Dados

Não compartilhamos, vendemos ou transferimos seus tokens de acesso ou dados de conta com nenhuma empresa ou serviço de terceiros.

2.4 Exclusão de Dados

Como os tokens são armazenados localmente no ambiente do usuário (em arquivo .env local), você pode revogar as permissões a qualquer momento desvinculando o aplicativo nas configurações da sua conta do TikTok ou apagando suas chaves locais.
